# 语境

语境是文字与读者共有的领域前提：这段字在谈什么、写给谁、按什么体裁写。它由语场、语旨、语式三者构成；三者缺一，适切性判定不完整。语境不是上下文；上下文是手头有哪些材料，语境是材料属于哪个领域、说给谁听。

三个概念取自语域理论的三分，合称语域。它们是约束条件，不是充分条件：通过检查只说明没有语用失误，不说明解释已被确定。

## 基本概念

**语场（F）** 是话语关涉的领域与话题范围。写小说、写工程说明、写财务报表，语场各不相同。

**语旨（T）** 是参与者之间的角色、关系与知识状态。同行读者接得住术语，普通读者接不住，这是语旨的差别。

**语式（G）** 是交际的渠道与体裁。合同、论文、随笔、聊天，各走各的渠道，各有各的规约。

**体裁**是有稳定规约的话语类型，是语式的具体形态。语式给出渠道，体裁给出该渠道上怎么写。

**语域**是三者合成的语言变体。同一段话换个语域，用词、句式与体例都会变。

旧称的惯例不单列：体裁规约归语式，语域期望归语旨。

## 形式化规则

判定对象是词项 w。语场、语旨、语式各有一个合取项，三项同时成立才算适切。

```text
语境 C = ⟨F, T, G⟩

违反语场(w, C) ⇔ ¬合语场(w, C)
违反语旨(w, C) ⇔ ¬合语旨(w, C)
违反语式(w, C) ⇔ ¬合语式(w, C)

适切(w, C) ⇔ 合语场(w, C) ∧ 合语旨(w, C) ∧ 合语式(w, C)
语用失误(w, C) ⇔ ¬适切(w, C)
              ⇔ 违反语场 ∨ 违反语旨 ∨ 违反语式
```

三个合取项可分别求值，失误因此能定位到维度，维度决定修复方向。三项各自怎么判，由目标语境的标注体系规定，本规格不预设粒度与算法。

- C1 参数先行：动笔前必须写明语场、语旨与语式；三者缺一，适切性判定不完整。
- C2 词随语境：词须同时合于语场、语旨与语式；跨语场使用时，改成目标语场惯用或该语场许可的说法，或用引号、反引号标为提及。
- C3 违约定向修复：判为语用失误的，按违反的维度修复——语场不合换词或说明词的所属领域，语旨不合调语域，语式不合换体裁许可的写法。读者需要先翻译才能理解的，仍算失误，不得以「看得懂」为由保留。
- C4 例外显式：本领域文档的术语落在语场之内，不算失误；引用与讨论术语须标为提及。标记只说明在讨论词本身，不是绕开修复的通道。

## 失误的名称

词形与义项的错位，近 Thomas 的语用语言失误；与角色关系或体裁不合，近社会语用失误。本规格只取「系统性偏离」这一层，不取跨文化对比的语境。

## 边界

- 约束不决定：三项检查全过，只说没有语用失误，不说明解释已被确定。
- 判定细则不在本规格：合语场、合语旨、合语式怎么算、标注到什么粒度，由各语境的标注体系另定。
