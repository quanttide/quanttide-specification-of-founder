# 语境

语境是文字与读者共有的领域前提：这段字在谈什么、写给谁、按什么体裁写。它由语场、语旨、语式三个参数组成，缺一不成语境。语境不是上下文；上下文是手头有哪些材料，语境是材料属于哪个领域、说给谁听。

三个参数取自语域理论的三分，是约束条件而非充分条件：全部通过，只说明没有语用失误，不说明解释已被确定。

## 三个参数

| 参数 | 含义 | 语用学来源 | 可标注表示 |
|------|------|------------|------------|
| F 语场 | 话语关涉的领域对象与话题范围 | Halliday 的 field | 领域标签、本体路径 |
| T 语旨 | 参与者的角色、关系与知识状态 | Halliday 的 tenor；Bell 的受众设计；Brown 与 Levinson 的权力、距离、强加度 | 参与者画像 |
| G 语式·体裁 | 交际渠道、体裁类型与规约期望 | Halliday 的 mode；Swales 与 Bakhtin 的体裁规约；Gumperz 的语境化线索 | 体裁规则集 |

- 语场 F 用领域标签或本体路径表示，检查时与词的领域标签做交集，或查本体映射。
- 语旨 T 用参与者画像表示：角色、专业水平、权力距离、共享知识域。画像给出语域等级的允许区间。
- 语式 G 用体裁规则集表示：体裁类型、渠道（书面、口头、数字）、该体裁许可的写法。

旧称的对象、读者、惯例不再单列：对象即语场，读者即语旨，惯例拆成两处，体裁规约进 G，语域期望进 T。

## 词的语用特征

一个词项 w 的语用特征记作 ⟨D, R, S⟩：领域标签集 D、语域向量 R（正式度、专业度等分量）、语体特征 S（缩略、口语、人称、术语密度等）。三项特征均可标注、可查询、可版本化，判定因此不依赖推理参与者此刻能调动什么假设。

## 形式化规则

```text
语境 C = ⟨F, T, G⟩
词项 w = ⟨D_w, R_w, S_w⟩

违反F(w, C) ⇔ D_w ∩ 路径(F) = ∅ ∧ ¬∃桥接映射
违反T(w, C) ⇔ ∃r ∈ R_w : r ∉ 区间(T)
违反G(w, C) ⇔ S_w ⊄ 许可(G)
语用失误(w, C) ⇔ 违反F ∨ 违反T ∨ 违反G
```

路径、区间、许可三个函数把参数投影到可比的空间：路径取语场下的标签集，区间取语旨允许的语域范围，许可取语式放行的语体特征集。检查是集合运算与约束满足，返回布尔值加违反维度，不停在「词属于哪个语境」的整体判断上。

- C1 参数先行：动笔前必须写明语场、语旨与语式；三者缺一，适切性与否无从判断。
- C2 词随参数：词项的三项特征须与 F、T、G 均不冲突；跨语场使用时，改成目标语场的日常说法，或用引号、反引号标为提及。
- C3 违约定向修复：判为语用失误的，按违反的维度与方向修复——违反 F 换词或加桥接注释，违反 T 调语域等级，违反 G 换体裁许可的形式。读者需要先翻译才能理解的，仍算失误，不得以「看得懂」为由保留。
- C4 例外显式：本领域文档的术语落在语场路径内，不算失误；引用与讨论术语须标为提及。标记只说明在讨论词本身，不是绕开修复的通道。

## 失误的分类

违反语场，偏语用语言失误：同一词形被指派了别一领域的义项。违反语旨与语式，偏社会语用失误：义项不差，与角色关系或体裁不合。两个名称取自 Thomas 的语用失误，本规格只取其中「系统性偏离」这一层，不取跨文化对比的语境。

输出的是偏离维度与方向，供修复或人工判断，不是一个是非结论。

## 边界与代价

- 约束不决定：三项检查全过，只说没有语用失误。这对应语用学「语境约束解释、不决定解释」的立场。
- 动态性压缩为参数更新：每轮交互后修订 T 的画像与 G 的规则集。这不等同语境化，只保留语境随交互变化的可操作内核。
- 认知可及性降为规约可及性：不建模参与者实际能调动什么假设，只建模该领域、该读者群、该体裁的标注体系允许什么。降级之后，检查可由词典、本体与规则库支撑。
- 判定质量取决于标注：D、R、S 缺标或标错时，检查退回人工。

## 术语

| 术语 | 来源 | 本规格用法 |
|------|------|------------|
| 语域 | Halliday | 由语场、语旨、语式构成的语言变体 |
| 语场 F | field | 谈什么领域、什么话题 |
| 语旨 T | tenor | 谁对谁说、什么关系、懂多少 |
| 语式 G | mode | 什么渠道、什么体裁、什么规约 |
| 体裁 | Swales、Bakhtin | 有稳定规约的话语类型 |
| 语境化线索 | Gumperz | 提示听者按哪套规约解读的信号 |
| 语用失误 | Thomas | 偏离规约的系统性错误，非偶然笔误 |
| 语用语言失误 | Thomas | 词形与义项的对应错位，本规格中对应违反语场 |
| 社会语用失误 | Thomas | 义项不差，与角色关系或体裁不合，对应违反语旨与语式 |
| 语域向量 R | — | 正式度、专业度等分量的标注向量 |
| 语体特征 S | — | 缩略、口语、人称、术语密度等形态特征 |
| 本体路径 | — | 领域标签在本体中从根到叶的路径 |
| 桥接映射 | — | 两个本体路径之间的等价或上下位映射 |
| 参与者画像 | Bell、Brown 与 Levinson | 角色、专业水平、权力距离、共享知识域 |
| 规约可及性 | — | 标注体系允许什么，替代认知可及性 |
