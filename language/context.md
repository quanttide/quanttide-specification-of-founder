# 语境

语境是文字与读者共有的领域前提：这段字在谈什么、写给谁、按什么体裁写。它由语场、语旨、语式三者构成。

## 组成部分

**语场（F）** 是话语关涉的领域与话题范围。写小说、写工程说明、写财务报表，语场各不相同。

**语旨（T）** 是参与者之间的角色、关系与知识状态。同行读者接得住术语，普通读者接不住，这是语旨的差别。

**语式（G）** 是交际的渠道与体裁。合同、论文、随笔、聊天，各走各的渠道，各有各的规约。

## 形式化规则

判断对象是词项 w。语场、语旨、语式各有一个合取项，三项同时成立才算适切。

```text
语境 C = ⟨F, T, G⟩

违反语场(w, C) ⇔ ¬合语场(w, C)
违反语旨(w, C) ⇔ ¬合语旨(w, C)
违反语式(w, C) ⇔ ¬合语式(w, C)

适切(w, C) ⇔ 合语场(w, C) ∧ 合语旨(w, C) ∧ 合语式(w, C)
语用失误(w, C) ⇔ ¬适切(w, C)
              ⇔ 违反语场 ∨ 违反语旨 ∨ 违反语式
```

三个合取项可分别求值，失误因此能定位到维度，维度决定修复方向。三项各自怎么判，由目标语境的标注体系规定，本规格不预设粒度与算法。

- C1 参数先行：动笔前必须写明语场、语旨与语式；三者缺一，适切性判断不完整。
- C2 词随语境：词须同时合于语场、语旨与语式；跨语场使用时，改成目标语场惯用或该语场许可的说法，或用引号、反引号标为提及。
- C3 违约定向修复：判为语用失误的，按违反的维度修复——语场不合换词或说明词的所属领域，语旨不合调语域，语式不合换体裁许可的写法。读者需要先翻译才能理解的，仍算失误，不得以「看得懂」为由保留。
- C4 例外显式：本领域文档的术语落在语场之内，不算失误；引用与讨论术语须标为提及。标记只说明在讨论词本身，不是绕开修复的通道。
- C5 例外须声明：本领域文档在文件头写 `context`，取值见文档契约；声明即生效，未声明按跨语场处理。
